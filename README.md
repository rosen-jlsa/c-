# C# Fundamentals Exercises

A collection of introductory C# exercises arranged by topic and practice week. The folders include conditional statements, loops, small console tasks, theory notes, and practice material.

## Browse the exercises

Start with the numbered tasks such as `01. Day of Week` and `02. Weekend or Working Day`, then move through the weekly theory and practice folders. Each exercise is kept in its own folder so it can be read independently.

This is learning material, not a single deployable application. Open an exercise in a C# capable editor and check its project files for the required .NET version before running it.
